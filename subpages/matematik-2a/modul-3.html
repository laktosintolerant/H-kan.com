📈 Modul 3: Potenser, PQ & Andragradsfunktioner

Förberedelse inför Prov Kapitel 2. Här tränar du på potenslagar, kvadreringsreglerna, konjugatregeln, nollproduktmetoden, andragradsekvationer med PQ-formeln, symmetrilinjer och extrempunkter samt exponentialfunktioner.

PQ-Lösaren ⚡ ← Alla moduler

📖 Nyckelformler för Modul 3

PQ-formeln

x = −(p/2) ± √((p/2)² − q)

Gäller för x² + px + q = 0 (dela med a om koefficienten framför x² ≠ 1).

Symmetrilinje

x = −p / 2

X-koordinaten för parabelns vändpunkt (maximi- eller minimipunkt).

Exponentialfunktion

y = C · a^x

C = startvärde, a = förändringsfaktor (t.ex. 0,85 vid 15% minskning).
